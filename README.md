# Folio — Freelancer Invoice Generator

Create clean, professional invoices with client details, line items, GST calculation, and one-click PDF download.

## Features

- Freelancer and client details
- Invoice number, date, and due date
- Editable line items (description, quantity, rate)
- Configurable GST rate with live totals
- Live invoice preview
- Download as PDF

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
